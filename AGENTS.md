# AGENTS.md

Canonical agent instructions live in [CLAUDE.md](CLAUDE.md).

Non-Claude agent consumers should read and follow `CLAUDE.md`. It is the index: mission, locked
technical decisions, and pointers into `docs/contracts/` (enforced rules) and `docs/reference/`
(annotated blocks, CLI usage, ship ritual).

There is no separate cross-tool contract to keep in sync — this file exists only so tools that look
for `AGENTS.md` find their way to the real one.
